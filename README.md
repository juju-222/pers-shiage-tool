# パース仕上げツール（pers-shiage-tool）

Lumionなどで書き出した建築パースを、ブラウザだけで仕上げるためのツールです。
Photoshopで行っていた「ソフトライトのブラシ」「トーンカーブ」「彩度」「ノイズ」などの仕上げを、1つの画面で行えます。

## 使い方

1. `index.html` をダブルクリックして、ブラウザ（Chrome・Edgeなど）で開きます。
2. 「画像を開く」を押すか、画像を画面にドラッグ＆ドロップします。
3. 左の「調整項目」で仕上げます。
4. 右上で「保存形式」と「解像度（dpi）」を選び、「保存」を押します（元の解像度で保存されます）。

## できること

| 項目 | 内容 |
|---|---|
| 明るさ・コントラスト・明るい部分・暗い部分 | 白い部分が急に真っ白にならないよう、ゆるやかに効きます |
| トーンカーブ | Photoshopと同じように点をドラッグして調整（RGB・赤・緑・青） |
| 彩度・色温度 | 色温度を変えても、黒い影には色がつきません |
| ブラシ | ソフトライトで「明るく」「暗く」「色をのせる」「消しゴム」 |
| 光のにじみ | 照明や窓の光をふわっとにじませます |
| 周辺減光・ぼかし・シャープ・粒状感 | ノイズは一番最後に入るので、シャープの影響を受けません |
| 範囲 | 各項目を、円で囲んだ場所だけに効かせられます（ドラッグで移動） |
| 拡大鏡（等倍） | 保存後と同じ大きさで細部やノイズを確認できます |
| 元画像と比較 | 画面を左右に分けて、仕上げ前と後を比べられます |
| 元に戻す・やり直す | Ctrl+Z／Ctrl+Shift+Z（Ctrl+Y）でも操作できます |
| プリセット | よく使う調整を名前を付けて保存できます |
| テクスチャマップ | 写真からノーマル・AO・ハイトマップを作れます（Blender用） |

## ショートカット

- `Ctrl + Z`：元に戻す
- `Ctrl + Shift + Z` または `Ctrl + Y`：やり直す
- `[` / `]`：ブラシの大きさを変える
- スライダーをダブルクリック：初期値に戻す
